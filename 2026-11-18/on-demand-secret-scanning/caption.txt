GitHub announced on-demand secret scanning for developers and agents on 17 November, in public preview.

Here’s what it does—and how to use it:

• What: Checks code changes for exposed secrets during Copilot security review.
• Why: Catch credentials before human-written or AI-generated code is merged.
• Where: Copilot CLI, app, SDK integrations and code review.
• How: In Copilot CLI, run /settings aiSecretDetection on, then /security-review.
• Limits: Opt-in, consumes AI credits, and checks changes—not repository history.
• Safeguards: Treat scans as one layer. Revoke exposed credentials, replace them securely and review findings before merge.
